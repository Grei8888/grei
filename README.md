# GREI — Personal Website

**Think Deep. Act Simple.**

A minimal, typography-first personal website inspired by Apple-style restraint and the mindset of systems builders.

## Files
- `index.html` — complete static site (HTML, responsive CSS, and a little JavaScript).

## Design
- Dark canvas, expressive white typography, restrained sage-green accent.
- No fake terminal windows, unnecessary frameworks, external fonts, analytics, or trackers.
- Works with GitHub Pages and modern mobile/desktop browsers.
- Work items link to the existing public repositories for NOAH.ark and ADDY.

## Publish on GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source: Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Once published, the expected site address is `https://grei8888.github.io/grei/`. GitHub must finish deploying before the link is live.
